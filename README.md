# Onshape Learning App

The first functionality in the app is the Grader.

### CAD Checking Functionality
- Checks for best practices
  - Renamed parts and features in Part Studios.
  - Assigned materials to the parts in Part Studios.
  - Details of instances and mates in Assemblies

- Checks for correctness in CAD model
  - Compares mass, volume, surface area and principal moment of inertial of user document with a reference document
